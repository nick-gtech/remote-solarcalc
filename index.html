About this application

Remote SolarCalc is a native Android application that lets field engineers size off-grid solar power systems for telecom towers and other remote network equipment. Each site record stores its location, DC system voltage, and the number of days the site must run without sun. Every site holds a list of the electrical loads installed there, and each load records its power draw in watts and its hours of use per day.

From those values the application totals the daily energy demand in watt-hours and recommends both the solar array wattage and the battery bank capacity in amp-hours. Engineers can search their saved sites by name or location, and the reporting screen lists every site with its recommended solar components under a title and a date and time stamp.

Installing on a device

  1. Open this page on the Android phone or tablet and tap Download APK.
  2. Android may warn that the file came from outside the Play Store. Allow installs from this browser when prompted, which is found under Settings → Apps → Special app access → Install unknown apps.
  3. Open the downloaded file and tap Install. The installer checks the release signature and refuses any modified copy of the file.
  4. Launch Remote SolarCalc from the app drawer.

First launch and sign in

The application is protected by a sign-in screen, and passwords are stored only as salted SHA-256 hashes on the device. No account is shipped with the download. The first launch shows a Create Account button, so the first person to open the app chooses their own username and password. Usernames need at least three characters and passwords need at least six. After that, the same screen signs the user in.

Release notes - version 1.0

  • Add, edit, and delete sites, each with a location, system voltage, and required days of autonomy.
  • Add, edit, and delete the equipment loads that belong to each site.
  • Solar sizing that recommends array wattage, panel count, and battery bank capacity.
  • Site search by name or location.
  • Sizing report with a title, a generated date and time stamp, and one row per site.
  • Sign-in screen with salted and hashed password storage.
